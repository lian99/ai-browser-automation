# AI-Assisted Browser Automation

A browser automation solution created for the STRAIX technical challenge using Claude Code.

## Goal

Navigate the challenge website, locate the question “How much is 1+1?”, and submit the correct answer.

## Approach

- Used Claude Code to help develop the automation.
- Guided the agent through the required browser interactions.
- Reviewed the result to verify task completion.

## Why I Built It

To explore how an AI coding agent can translate a plain-language task into browser actions and help automate repetitive workflows.
